# 사전 역량 기르기
## 목적
1. ai활용능력 강화
2. 팀으로 성장하기
3. 안전하게 말하기
## 주의사항
1. 매일 15분 내용을 루틴으로 잡을 것.(20분 멕시멈)
2. 20분을 초과 시 과감하게 일상으로 돌아올 것.(욕심 내서 하기 금지)
3. 당일 밤에 슬랙에 다음을 작성해서 올릴 것. (양식: MM_DD_'파일 명')
   * 오늘 한 일 : 
   * 부족한 점 : 아쉬운 점, 그로 인해 배운 점, 내일 더 노력할 점 등 자유롭게 기록.
   * 잘한 점 : 내일도 이어갈 점 기록
   * 의문점 : 아이디어 공유를 위한 기록
